Package artistlib

The aRTist Python library is designed to remotely control and automate the radiographic simulation software aRTist.

Hint: This project is in its early stages and may change significantly over time.

Getting started

Requirements

A Python 3 environment (Python 3.8 or higher) is required. The following Python packages are required as well. They usually come with a Python environment, or can be installed there easily:

  • none so far.

Installation

If you want to install the package in your Python environment, you can use pip. For example, you can run the following command to make the toolbox available:

pip install artistlib

To use the package without installation, you need to download the package manually. You have the following three options:

  • Download the package from PyPi. You will get a zipped file called artistlib-X.X.X.tar.gz (where X.X.X is the current version number). Open or unpack this file to get to its contents.
  • Download the repository from GitHub: press the clone button to download a ZIP file. Unpack it or open it to see its contents.

  • You can also clone the repository from GitHub via the terminal:

    git clone https://github.com/BAMresearch/aRTist-PythonLib.git

From any of these three options, you will get the complete package source code. It contains a folder called artistlib. If you want to use the library from your Python scripts without installing it, you need to copy the folder artistlib to the location of your Python scripts to make the package available.

About

The aRTist library was developed for utilize the Python scripting of the radiographic simulator aRTist.

The software is released under the Apache 2.0 license, its source code is available on GitHub.

Usage

Please make sure that aRTist is running and waiting for remote connection (menu: Tools>Enable remote access).

The following example code shows the basic usage:

import artistlib as a
# from artistlib.junction import Junction

# connect to aRTist (default: host='localhost', port=3658)
jct = a.Junction()


# print aRTist's version number
ver = jct.send("::aRTist::GetVersion full")
print(ver)

# - load a project
# - run the simulation
# - save the resulting projection from the image viewer
jct.send("FileIO::OpenAny $Xray(LibraryDir)/ExampleProjects/Schlumpfmark.aRTist")
jct.send("Engine::GoCmd")
ans = "Saved as: "
ans += jct.send(
    "Modules::Invoke ImageViewer SaveFile [file join $env(HOME) Pictures/artistlib.tif] true"
)
print(ans)

# - load a project
# - run the simulation without viewing the result
# - transfer the final projection
# - saving the projection image  >>>> This requires aRTist 2.12.7 or higher! <<<<
# - delete the images to release the memory
jct.send("FileIO::OpenAny $Xray(LibraryDir)/ExampleProjects/aRTist.aRTist")
jct.send("set imgList [Engine::Go]")
jct.send("RemoteControl::SendImage [lindex $imgList 0]")
jct.get_image("transferred.tif")
jct.send("foreach i $imgList {$i Delete}")

Usage of the wrapper

The following example code shows the basic usage of the Wrapper:

import artistlib as a
from pathlib import Path

project_folder = "$Xray(LibraryDir)/ExampleProjects/Dragon-CT.aRTist"
result_folder = Path.home() / "Pictures"
# Starts aRTist and activates remote control.
# a.ArtistAll() also starts aRTist and activates remote control.
a.start_artist()
wrapper = a.ArtistAll()
# Loads a project (.artist) or a part (.stl) based on the provided path.
wrapper.load_project(project_folder)

# Translation of the part with the given ID, to the given coordinates.
#
# part_orientation rotates the part with the given ID
# part_material sets the material of the part with the given ID.
wrapper.part_position_global(ID=1, x=10, y=10, z=-10)
wrapper.part_position_global(ID=1, x=30)
wrapper.part_orientation(1, angleX=90, angleY=45, angleZ=10)
wrapper.part_material(1, "Al")

# Translation of the detector.
# Rotation of the detector.
# detector_geo can change the Detector Geometry with Detector_Geo, which means changing either Pixel and Size or Pixel and Resolution or Size and Resolution.
wrapper.detector_position(x=30, y=20)
wrapper.detector_orientation(x=5)
wrapper.detector_geo(size=100, pixel=600)

# Translation of the source.
# Rotation of the source.
wrapper.source_position(z=155)
wrapper.source_orientation(x=1)

# Sets the individual values of the spectrum.
# Calculates the spectrum and saves it to a path.
wrapper.set_spectra(
    "Tube3", 300, "W", 12, 0.3, "Cu", 0.5, "Cu", 0.5, "Cu", 0.5, "Be", 1.0, 12, 1, 1.0
)
wrapper.cal_spectra(spec_name="Tube3_spc.xrs", dest_path=result_folder)

#
# Loads a dict file and extracts spectrum values and calculates the spectrum.
# Loads an already calculated spectrum.
load_folder = Path(__file__).parent / "Test_tub3.dict"
wrapper.load_tube(
    path_dict=load_folder, spec_name="Test_tub3.xrs", path_dest=result_folder
)
wrapper.load_spectra((result_folder / "Tube3_spc.xrs"))

# Runs the current project, starts the simulation.
# Saves the image to a path with a given name.
wrapper.run_project()
wrapper.save_img_project(result_folder, "Pic2.tif")

# Deletes a part with the given ID.
# Resets artist.
wrapper.delete_part(ID=1)
wrapper.clear_project()

# closes aRTist.
# a.close_artist()

class Junction:
    """Provides remote control functionality for the aRTist simulator."""

    def __init__(self, host="localhost", port=3658, bufferSize=1024, timeout=5):

        self.host = host
        self.port = port
        self.bufferSize = bufferSize
        self.timeout = timeout
        self.error = 0
        self.progress = 0
        self.answer = {}

        self.connect()

    def connect(self):
        self.S = socket.socket()  # Create socket (for TCP)
        self.S.connect((self.host, self.port))  # Connect to aRTist
        self.S.settimeout(self.timeout)
        self.listen(0)
        return self

    def send(self, command, msgType="RESULT"):
        c = command + "\n"
        self.S.send(c.encode())
        return self.listen(msgType=msgType)

    def listen(self, command_no=1, msgType="RESULT"):
        answer = ""
        stop = False
        if command_no == 0:
            self.S.settimeout(0.2)
        while not stop:  # and ("SUCCESS" not in total) and ("ERROR" not in total):     # Solange server antwortet und nicht "SUCCESS" enthält
            try:
                msg = self.S.recv(self.bufferSize).decode()

            except socket.timeout:
                answer += "RESULT Timeout\n"
                stop = True
                continue
            except OSError as e:
                answer += f"RESULT SocketError {e}\n"
                stop = True
                continue
            else:
                if "SUCCESS" in msg:
                    answer += msg
                    stop = True
                    continue
                elif "ERROR" in msg:
                    answer += msg
                    stop = True
                    # global error
                    self.error = self.error + 1
                    continue
                elif "PROGRESS" in msg:
                    try:
                        self.progress = float(msg.strip("PROGRESS "))
                    except Exception:
                        self.progress = 0
                    continue
                else:
                    if command_no == 0:
                        logger.debug(msg)
                    answer += msg
                if msg == "":
                    break

        self.S.settimeout(self.timeout)
        self.answer.update(
            {
                "SUCCESS": self.pick(answer, "SUCCESS"),
                "RESULT": self.pick(answer, "RESULT"),
                "SDTOUT": self.pick(answer, "STDOUT"),
                "BASE64": self.pick(answer, "BASE64"),
                "IMAGE": self.pick(answer, "IMAGE"),
                "FILE": self.pick(answer, "FILE"),
            }
        )
        if msgType != "*":
            answer = self.pick(answer, msgType)
        return answer

    def pick(self, answer, res="RESULT"):
        picked = ""
        for a in answer.split("\n"):
            if a.find(res) == 0:
                picked += a[1 + len(res) :].strip("\r") + "\n"
        if len(picked) == 0:
            return res + " not found."
        return picked

    def get_answer(self, key):
        return self.answer[key]

    def disconnect(self):
        try:
            self.S.shutdown(socket.SHUT_RDWR)
        except Exception:
            pass
        self.S.close()

    def get_image(self, imageName: str) -> tuple[Image.Image, np.ndarray]:

        npTypes = [
            np.bool_,
            np.ubyte,
            np.byte,
            np.ubyte,
            np.short,
            np.ushort,
            np.intc,
            np.uintc,
            np.int_,
            np.uint,
            np.single,
            np.double,
        ]
        try:
            imageData = self.answer["BASE64"]

            decodedData = base64.b64decode((imageData))

            imageHeader = self.answer["IMAGE"].split()
            dtype = npTypes[int(imageHeader[4])]
            im = np.frombuffer(decodedData, dtype).reshape(
                (int(imageHeader[1]), int(imageHeader[0]))
            )

            return Image.fromarray(im), im

        except Exception as e:
            logger.exception("Error decoding image %s", imageName)
            # es handelt sich um einen Fehler und wir geben eine fallback Bild und array zurück
            size = (141, 141)
            arr_fallback = np.zeros(size, dtype=np.uint8)
            img_fall = Image.fromarray(arr_fallback)
            return img_fall, arr_fallback

    def save_disk(self, im: np.ndarray, imageName: str) -> None:
        Image.fromarray(im).save(imageName)

    # speichert direkt aus dem Image Object, sollte schneller sein
    def save_disk_imgObject(self, Img: Image.Image, imageName: str) -> None:
        Img.save(imageName)

    def receive_file(self, fileName):
        fileData = self.answer["BASE64"]
        decodedFile = base64.b64decode((fileData))
        artistFile = open(fileName, "wb")
        artistFile.write(decodedFile)
        artistFile.close()

    def send_file(self, fileName):
        outFile = open(fileName, "br")
        fileBytes = outFile.read()
        encBytes = base64.b64encode((fileBytes))
        encString = str(encBytes)
        encString = encString.lstrip("b'").rstrip("'")
        fileExtension = pathlib.Path(fileName).suffix
        com = "::RemoteControl::ReceiveFile " + encString + " " + fileExtension
        recAnswer = self.send(com, "RESULT")
        return recAnswer

class ArtistSend:
    """This class validates user input and sends the resulting Tcl commands to aRTist."""

    _jct = None  # gemeinsame Instanz
    _global_batch = False
    _batch_list = []

    def __init__(
        self,
        batch: bool = None,
        host="localhost",
        port=3658,
        bufferSize=1024,
        timeout=5,
    ):
        if ArtistSend._jct is None:
            ArtistSend._jct = Junction(host, port, bufferSize, timeout)
        self.jct = ArtistSend._jct

        self.batch_flag = batch if batch is not None else self.__class__._global_batch

    @classmethod
    def set_global_batch(cls, value: bool):
        """Enables batching mode when set to `True`. Function calls are stored and sent together.
        **Note:** Batching can improve performance, but some functions may behave differently. Use the `apply()` function to send the accumulated commands."""
        cls._global_batch = value

    def apply(self) -> str:
        """Sends the batched command list to aRTist in chunks."""
        a = ""
        chunk_size = 300
        list_chunk = [
            ArtistSend._batch_list[i : i + chunk_size]
            for i in range(0, len(ArtistSend._batch_list), chunk_size)
        ]
        for elements in list_chunk:
            cmd = "".join(elements)
            a += self.jct.send(cmd)
        ArtistSend._batch_list.clear()
        return a

    def send(self, cmd: str) -> str:
        """Sends Tcl commands directly to aRTist or stores them in the batch queue if batching is enabled."""
        if self.batch_flag is True:
            cmd_fin = cmd.strip("\n") + " ; "
            ArtistSend._batch_list.append(cmd_fin)
            return cmd_fin

        response = self.jct.send(cmd)
        return response

    def _isnumber(self, val) -> bool:
        if isinstance(val, numbers.Number) or val is None:
            return True
        else:
            raise TypeError("Only numbers are allowed", val)

    def _is_str_safe(self, string) -> None:
        if string is None:
            return
        if isinstance(string, str):
            if "[" in string or ";" in string or "\n" in string or "{" in string:
                raise Exception(
                    r"Risk of TCL injection, do not use '[' , ';' , '\n','{' in your string",
                    string,
                )
        else:
            raise Exception("Input is not a string", string)
        return

    def _replace_slashes(self, path: str) -> str:
        path = str(path)
        return path.replace("\\", "/")

    def _is_path_safe(self, path) -> str:
        path = str(path)
        path = path.replace("\\", "/")
        # not the best solution, because TCL path is solved in Artist
        if "$" in path:
            return path
            # if os.path.exists(path) or "$" in path:
        path = Path(path).expanduser()  # ~ auflösen
        path = path.resolve()  # absolut + sauber
        path = path.as_posix()  # "/" statt "\"
        return path

    def _control_str(self, *args) -> None:
        for a in args:
            self._is_str_safe(a)

    def _control_number(self, *args) -> None:
        for a in args:
            self._isnumber(a)

    def _control_path(self, *args) -> str:
        paths = [None] * len(args)
        i = 0
        for a in args:
            paths[i] = self._is_path_safe(a)
            i = i + 1

        return paths

    def _path_exist(self, *args) -> None:
        for a in args:
            if "$" in a:
                continue
            p = Path(a)
            if not p.exists():
                raise Exception("path does not exist", p)

    def load_file(self, path: str) -> str:
        """Loads a file into aRTist from the specified path."""
        path_s = str(path)
        self._control_str(path_s)
        path_s = self._control_path(path_s)[0]
        self._path_exist(path_s)
        a = self.send(f'::FileIO::OpenAny "{path_s}"')
        return a

    """This class provides functions for modifying the source."""

    List_content = [
        "Name",
        "Voltage",
        "TargetMaterial",
        "TargetAngle",

        "WindowMaterial",
        "TargetMaterial",
        "FilterMaterial",
        "Filter2Material",
        "Filter3Material",

    def _copy_and_rename(self, src_path: str, dest_path: str, new_name: str) -> None:
        try:
            # Datei kopieren
            copied_file = shutil.copy(src_path, dest_path)

            # Neuer kompletter Pfad mit neuem Namen
            new_path = self._replace_slashes(os.path.join(dest_path, new_name))

            # rename
            shutil.move(copied_file, new_path)

        except Exception:
            logger.exception("Unexpected error while copying and renaming file")
            raise

    def cal_spectra(
        self, spec_name: str = None, dest_path: str = None, reduce_number_bins=False
    ):
        """Calculates a spectrum and optionally saves it.

        Note:
        * If no output path is specified, the spectrum is calculated but not saved.
        * Spectrum calculation may take longer for high-voltage configurations.
        * Set reduce_number_bins to True to reduce the number of bins in the spectra to a maximum of 128 bins.
        """
        a = ""
        if self.batch_flag:
            if spec_name is not None or dest_path is not None:
                logger.warning(
                    "When using batch mode, no storage location can be specified for the calculation."
                )
            a += self.send("::XSource::ComputeSpectrum")
            if reduce_number_bins is True:
                a += self.send("::XSource::CheckSpectrum")
            return a

        # we need to set the timeout high, because the calculation can take a long time for high voltage

        old_timeout = self.jct.timeout
        self.jct.timeout = 1000
        self.jct.S.settimeout(self.jct.timeout)
        try:
            path1 = self.send("::XSource::ComputeSpectrum").strip("\n")
            if path1 == "Timeout" or path1 == "{}":
                raise RuntimeError(
                    f"Spectrum calculation failed (timeout: {self.jct.timeout}s) or unexpected error."
                )
            a += path1
            if reduce_number_bins is True:
                a += self.send("::XSource::CheckSpectrum")
        finally:
            self.jct.timeout = old_timeout
            self.jct.S.settimeout(self.jct.timeout)

        if dest_path is not None:
            dest_path = self._control_path(dest_path)[0]
            self._path_exist(dest_path)
            self._control_str(dest_path)

            if spec_name is not None:
                self._control_str(spec_name)

            self._copy_and_rename(
                src_path=path1, dest_path=dest_path, new_name=spec_name
            )

        return a

    def _read_file(self, path: str) -> None:
        with open(path, "r") as f:
            return f.read()

    def _get_content_dict(self, content: str) -> list:

        list_spectrum = []

        for el in self.List_content:
            match = re.search(rf"\b{el}\b\s+([^\s]+)", content)

            if el in self.STRING_FIELDS:
                if match:
                    list_spectrum.append(match.group(1))
                else:
                    list_spectrum.append(None)

            else:
                if match:
                    list_spectrum.append(float(match.group(1)))
                else:
                    list_spectrum.append(None)
        return list_spectrum

    def load_tube(self, path_dict: str, spec_name: str, path_dest: str) -> None:
        """Loads a `.dict` file, applies the spectrum settings, and calculates the resulting spectrum."""
        path_dict, path_dest = self._control_path(path_dict, path_dest)
        self._path_exist(path_dict, path_dest)
        self._control_str(path_dict, spec_name, path_dest)
        try:
            content = self._read_file(str(path_dict))

            values_spec = self._get_content_dict(content)

            self.set_spectra(*values_spec)

            self.cal_spectra(spec_name, str(path_dest))
        except Exception:
            logger.exception("Unexpected error while loading tube data")
            raise

    def get_spectra(self):
        """Gets the current spectrum and returns it as a dict."""
        spectrum_dic = {}
        for el in self.List_content:
            out = self.send("array get Xsource " + el).split(" ")[1].strip("\n")
            if el in self.STRING_FIELDS:
                spectrum_dic[el] = out
                continue
            if out != "{}" and out != "":
                spectrum_dic[el] = float(out)
                continue
            spectrum_dic[el] = out

        return spectrum_dic

    def get_spectra_one_value(self, spectrum_parameter):
        """Returns only the specified spectrum parameter.
        **Note**:
        * Possible values are:
        'Name', 'Voltage', 'TargetMaterial', 'TargetAngle', 'TargetThickness', 'FilterMaterial', 'FilterThickness', 'Filter2Material', 'Filter2Thickness', 'Filter3Material', 'Filter3Thickness', 'WindowMaterial', 'WindowThickness', 'AngleIn', 'Transmission', 'Resolution'.
        """

        self._control_str(spectrum_parameter)

        if spectrum_parameter in self.List_content:
            out = (
                self.send("array get Xsource " + spectrum_parameter)
                .split(" ")[1]
                .strip("\n")
            )
            if spectrum_parameter in self.STRING_FIELDS:
                return out
            if out != "{}" and out != "":
                return float(out)
            return out
        else:
            logger.warning("Wrong spectrum_parameter please use: ", self.List_content)

    def set_source_type(self, source_type: str = "Mono"):
        """Sets the type of the source.
        **Note**
        * source_type has to be either "Mono" or "General".
        """
        if source_type not in ("Mono", "General"):
            logger.warning("source_type must be either 'Mono' or 'General'")
            return ""

        return self.send(f"set ::Xsource(Tube) {source_type}")

class MaterialService(ArtistSend):
    def add_material(
        self,
        m_name: str = "dummy",
        density: float = 0,
        composition: str = "Al",

            + " {density "
            + str(density)
            + " composition {"
            + str(composition)
            + "} comment {"
            + str(comment)
            + "}}"
        )
        a += self.send("Engine::ClearMaterials")
        self.send(("::Materials::RefreshTable"))
        return a

    def delete_material(self, m_name: str):
        self._control_str(m_name)
        a = self.send("dict unset ::Materials::MatList " + str(m_name))
        self.send(("::Materials::RefreshTable"))
        return a

    def _brace_to_quotes(self, text):
        """Helper utilities for working with Tcl dictionaries."""
        return re.sub(r"\{([^}]+)\}", r'"\1"', text)

    def names_material(self):
        mat_list = self.send(("dict keys $::Materials::MatList"))
        return shlex.split(self._brace_to_quotes(mat_list))

    def pick_material(self, mname):
        """Retrieves a material definition from aRTist."""
        list = self.names_material()
        if mname in list:
            mat = self.send("dict get $::Materials::MatList " + mname)
            mat = shlex.split(self._brace_to_quotes(mat))
            mat = dict(zip(mat[::2], mat[1::2]))
            if "comment" in mat:
                return mname, mat["density"], mat["composition"], mat["comment"]
            return mname, mat["density"], mat["composition"]
        else:
            return ""

    def in_parts(self, path: str) -> list[Part]:
        """Creates Python objects from the parts currently available in aRTist."""
        # wenn es ein neues Project ist (.aRTist) File dann werden alle ID und token ersetzt
        if path.endswith(".aRTist"):
            self.matches = None
            # for part in Part._instances:
            for part in self.parts_instances:
                part._destroyed = True
            # Part._instances.clear()
            self.parts_instances.clear()
        self.A.load_project(path)
        part_list = self._sync_parts()
        return part_list

    def _get_state(self) -> list[str]:
        """Retrieves the current part IDs and tokens from aRTist."""
        ans = self.A.send("::PartList::Get")
        pattern = r"(\S+)\s+\{Name(?:[^\{\}]|\{[^\}]*\})*?\s+Token\s+(\S+)"
        # pattern=r"(\S+)\s+\{Name\s+.*?Token\s+(\S+)"
        return re.findall(pattern, ans)

    def _sync_parts(self) -> list[Part]:
        """Creates Python objects for parts that do not yet have corresponding objects."""
        new_matches = self._get_state()
        matches = self.matches
        part_list = []
        if matches is None:
            for ID, token in new_matches:
                if ID == "D" or ID == "S":
                    continue
                p = Part(self, ID, token)
                part_list.append(p)

            self.matches = new_matches
            return part_list

        token_list_matches = {t[1] for t in matches}

        for ID, token in new_matches:
            if ID == "D" or ID == "S":
                continue

            if token not in token_list_matches:
                p = Part(self, ID, token)
                part_list.append(p)

        self.matches = new_matches
        return part_list

    def _update_state(self) -> None:
        """Updates part IDs and tokens."""
        new_matches = self._get_state()
        matches = self.matches

        if matches is None:
            self.matches = new_matches
            return

        if set(new_matches) != set(matches):
            self._sync_parts()

            # löscht die alten Parts anhand der token

            old_token = {t[1] for t in matches}
            new_token = {t[1] for t in new_matches}
            removed_tokens = old_token - new_token

            # for part in list(Part._instances):
            for part in list(self.parts_instances):
                if part.token in removed_tokens:
                    part._destroyed = True
                    self.parts_instances.remove(part)

    def clear_project(self) -> list[Part]:
        """Clears the virtual scene."""
        self.A.clear_project()
        for part in self.parts_instances:
            part._destroyed = True
            # Part._instances.clear()
        self.parts_instances.clear()
        return self._sync_parts()

    def update_project(self) -> None:
        """This function updates the state of all parts in this project."""
        for part in list(self.parts_instances):
            part.update_part()

    def source(self) -> Source:
        return self._source

    def detector(self) -> Detector:
        return self._detector

class Part:
    """This class creates a Python object based on the configuration in Artist."""

    def __init__(self, project_obj, ID, token):
        self._destroyed = False
        self.pro = project_obj
        self.pro.parts_instances.append(self)

        self.ID = ID
        self.token = token
        self.x = None
        self.y = None
        self.z = None
        self.x_ref = None
        self.y_ref = None
        self.z_ref = None
        self.angleX = None
        self.angleY = None
        self.angleZ = None
        self.material = None

        self._get_artist_values()
        self._old_part = {}
        self._sync_old()

    def update_part(self) -> str:
        """Applies modifications to Artist."""
        ans = ""
        self.pro._update_state()

        if (self.x, self.y, self.z) != (
            self._old_part["x"],
            self._old_part["y"],
            self._old_part["z"],
        ):
            ans += self.pro.A.part_position_global(int(self.ID), self.x, self.y, self.z)

        if (self.angleX, self.angleY, self.angleZ) != (
            self._old_part["angleX"],
            self._old_part["angleY"],
            self._old_part["angleZ"],
        ):
            ans += self.pro.A.part_orientation(
                int(self.ID), self.angleX, self.angleY, self.angleZ
            )

        if (self.x_ref, self.y_ref, self.z_ref) != (
            self._old_part["x_ref"],
            self._old_part["y_ref"],
            self._old_part["z_ref"],
        ):
            ans += self.pro.A.part_position_ref(
                int(self.ID), self.x_ref, self.y_ref, self.z_ref
            )

        if self.material != self._old_part["material"]:
            ans += self.pro.A.part_material(int(self.ID), self.material)

        self._get_artist_values()
        self._sync_old()
        return ans

    def delete_part(self) -> str:
        """Removes the specified part from Artist."""
        if self._destroyed:
            raise ReferenceError("Part already destroyed")

        self.pro._update_state()
        ans = self.pro.A.delete_part(int(self.ID))
        self.pro._update_state()
        self._destroyed = True
        return ans

    def _sync_old(self) -> None:
        self._old_part = {
            "x": self.x,
            "y": self.y,
            "z": self.z,
            "x_ref": self.x_ref,
            "y_ref": self.y_ref,
            "z_ref": self.z_ref,
            "angleX": self.angleX,
            "angleY": self.angleY,
            "angleZ": self.angleZ,

        self.x, self.y, self.z = self.pro.A.get_part_global(int(self.ID))
        self.angleX, self.angleY, self.angleZ = self.pro.A.get_part_orientation(
            int(self.ID)
        )
        self.x_ref, self.y_ref, self.z_ref = self.pro.A.get_part_ref(int(self.ID))
        self.material = self.pro.A.get_part_material(int(self.ID))
